# Library Management System (WAP 228 Project)

This project is a lightweight, terminal-based **Library Management System** developed as part of the WAP 228 course. It successfully integrates core programming concepts with local relational database management.

##  Key Features
* **Book Management:** Add, list, update, and remove books within the system.
* **Member Management:** Track library member registrations and profiles.
* **Transaction Tracking:** Seamlessly manage borrowing and returning activities using relational mapping.
* **Data Safety:** Implemented with safe `try-except` blocks and parameterized SQL queries to ensure integrity and prevent crashes.

---

##  Tech Stack
* **Programming Language:** Python 3
* **Database Engine:** SQLite3 (Embedded, local file persistence via `library.db`)
* **Version Control:** Git & GitHub
